# Module 1 Assignment: Intro to DSA & Python Collections

Welcome to your first assignment! This module covers the foundational concepts of **Data Structures and Algorithms (DSA)**, the difference between Abstract Data Types (ADTs) and concrete implementations, and how to use Python’s built-in collection types efficiently.

---

## 🎯 Learning Objectives

- **Understand Core Collections**: Gain hands-on experience with Python’s built-in structures (`list`, `string`, `dict`, `tuple`, and `set`).
- **Mutability vs Immutability**: Learn when to use mutable, immutable, ordered, and unique collections.
- **Simulate ADTs**: Bridge the gap between theoretical Abstract Data Types (like List, Set, Map, Priority Queue, Graph) and practical Python implementations.
- Develop good coding practices and understand basic time complexity.
